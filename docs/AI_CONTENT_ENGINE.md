# AI-powered Content Generation & Website Analysis

## 🤖 AI Content Engine Features

### Website Analysis
- Automatische Extraktion von Metatags und Keywords
- Titel, Beschreibungen, Überschriften auslesen
- Bilder und Favicon erkennen
- Text-Content extrahieren
- Zielgruppe und Themen inferieren

### Content Generation
- **7-Tage-Plan** pro Social-Media-Kanal
- Unterschiedliche Post-Typen (Reels, Carousel, Story, Post)
- Kanal-spezifische Content-Strategien:
  - **Instagram:** Visuell, Engagement-fokussiert
  - **LinkedIn:** Thought Leadership, B2B-Content
  - **Facebook:** Community-Engagement
  - **X/Twitter:** Trends, Quick Tips

### Smart Features
- Automatische Hashtag-Generierung
- Kanal-optimierte CTAs
- Tone-of-Voice Anpassung
- Keyword-basierte Content-Vorschläge

## 🔄 Content Generation Flow

```
1. User gibt Website-URL ein
   ↓
2. Website-Analyzer extrahiert Metadaten
   ↓
3. AI-Engine analysiert Inhalte
   ↓
4. 7-Tage-Content-Plan wird generiert
   ↓
5. Posts werden in Datenbank gespeichert
   ↓
6. User sieht Vorschau im Dashboard
```
